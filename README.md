Demonstração Web para FolEs (linguagem de folhas de estilo em português) e
LMHT (Linguagem de Marcação Hiper Texto — HTML em português). Este repositório
contém uma pequena página estática que mostra como integrar `FolEs` com
`LMHT` para gerar páginas HTML estilizadas com sintaxe em português.

## Características

- Exemplo de uso de `LMHT` como alternativa de marcação em português.
- Uso de `FolEs` para escrever folhas de estilo em português e gerar CSS.
- Arquivos de exemplo prontos para teste no diretório raiz (`index.html`).

## Demo

Abra `index.html` no seu navegador para testar a demonstração. A página mostra
o uso de LMHT para estrutura e FolEs para estilos.

## Pré-requisitos

- Navegador moderno (Chrome, Edge, Firefox, etc.).

## Deploy — GitHub Pages

Habilite o Pages nas configurações do repositório (`Settings` → `Pages`) e
selecione a branch `principal` e pasta `/ (root)` para publicar. Alternativamente,
adicione o workflow de GitHub Actions `.github/workflows/deploy-gh-pages.yml`
para automatizar o deploy para a branch `gh-pages` (exemplo incluído no
repositório).
